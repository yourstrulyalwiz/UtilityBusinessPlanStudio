# Optimization Studio — Reusable Brand Guide

## Purpose
This guide documents the visual style implemented in Optimization Studio so it can be reused in another project. It is a practical specification of the current application, not a reproduction or certification of the original institutional brand book.

The identity combines a navy base with cyan, lime and orange accents. It is designed for analytical tools: clear information, legible indicators, compact controls and accessible explanations.

Reused: palette, typography, hierarchy, components, iconography and interaction rules.
Not copied automatically: product name, utility data, formulas, indicators, sources, permissions, institutional text or simulator functionality. The new project defines these for its own purpose.

## 1. Main palette

| Deep navy | #29323F | Inner blocks, metrics, higher-contrast surfaces |
| Card navy | #3B475B | Cards on the main background |
| Navy border | #4A5770 | Separators and borders on dark surfaces |
| Cyan | #1ED3D9 | Primary action, selection, focus, main series |
| Lime | #D9E950 | Positive emphasis, highlighted selection, high impact |
| Orange | #FF6A0D | Warnings, adverse effects, transitions |
| Neutral gray | #D9D9D9 | References and baselines |
| Supporting green | #70AD47 | Secondary positive indicators |
| Light text | #EEF2F6 | Main text on dark backgrounds |
| Muted light text | #AEB8C6 | Secondary descriptions on dark backgrounds |

Complementary light surfaces:
- Panel background: #F7F9FB
- Card: #FFFFFF
- Border: #E3E8EE
- Main text: #323D4F
- Secondary text: #5B6678 or #6B7687
- Soft cyan accent: #E4F8F9
- Soft warning: #FFF1E8 with dark text #9A3A05

Fidelity note: some current cards and badges use the lime variant #D6E865. For a new project, consolidate on #D9E950.

### Usage rules
1. Navy dominates the composition; accents signal actions or important information.
2. Cyan buttons use navy text, not white.
3. Cyan and lime are not suitable for small text on white. Use dark text or a filled badge.
4. Never communicate status through color alone: add text, an icon or a sign.
5. Check the contrast of every real combination. Target WCAG AA: 4.5:1 for normal text, 3:1 for large text.

## 2. Typography
- Primary: Inter, weights 400, 500, 600, 700.
- Monospace: JetBrains Mono, weights 400 and 500, for identifiers, code and technical data. Fallback: Menlo, monospace.
- Indicator values use tabular figures: `.metric { font-variant-numeric: tabular-nums; }`

Indicative scale:
- Page title: 30 px, weight 600
- Card or panel title: 17 px, weight 600
- Main metric: 28 px, weight 600
- Compact text and buttons: 12–14 px
- Secondary label or help: 10–11 px, only for complementary information, never for essential instructions

On mobile, increase sizes and touch targets where needed; do not shrink everything to keep a desktop layout.

## 3. Layout and spacing
Reusable patterns, not mandatory for every product:
- Spacing base: multiples of 4 px
- Usual gap between groups: 16–24 px
- Card padding: about 20 px
- Control radius: 6–8 px
- Main card radius: 12–16 px
- Thin border and soft shadow, no exaggerated glow
- Generous but organized content; avoid both clutter and excessive empty space
- Reference portfolio shadow: `box-shadow: 0 14px 40px rgba(10, 15, 25, 0.35);`
- Content width limited to about 1280 px; cards collapse to one column on small screens.

## 4. Components
**Primary button:** background cyan #1ED3D9, text navy #29323F weight 600, radius 8 px, 40 px visual height (44 × 44 px minimum touch area), direct English label ("Open dashboard", "Create project", "View details"), discreet hover and visible keyboard focus.

**Secondary button:** on dark, a slightly different navy surface with light text; on light, a neutral border with navy text. Unavailable controls are disabled and explain why.

**Card:** surface #3B475B on #323D4F; light title, secondary description, metrics and a primary action. Metrics may sit in a #29323F block. Hover may highlight the border in cyan.

**Context panel:** background #F7F9FB, navy headings, #E3E8EE separators, active tab underlined in cyan, independent scroll, selected item's identity always visible.

**Badges and states:**
- High: lime, navy text
- Medium: cyan, navy text
- Low: slate #5A6780, light text
- Adverse / Warning: orange, or soft orange surface with dark text
- Loading: explicit "Calculating…" or "Loading…", never invented values

Thresholds behind these labels must be defined and explained in each product.

## 5. Charts and data
- Main series: cyan. Highlighted comparator: lime. Baseline: gray, preferably dashed.
- Negative changes or warnings: orange, with a sign and a label.
- Always show units, period, legend and source.
- Never mix incompatible units on one axis.
- Distinguish observed data, scenarios and modeled results.
- Show "No data" when observations are missing; never substitute zero.
- Do not introduce figures or demo data unless the user supplies or explicitly authorizes them.

## 6. Logo and iconography
The application symbol is a circular hub: a central node connected to six outer nodes, inside a thin circular outline (`optimization-studio-hub.svg`).
- Cyan lines and outline; outer nodes alternate cyan, lime and orange; navy center with cyan border.
- Usual size: 32–34 px.
- It is the application's symbol, not an official institutional logo. Change the name next to it for each product.
- Interface icons: Lucide, simple consistent outlines, 14–20 px. No emojis as functional icons.
- Do not add institutional names, seals or logos that suggest affiliation without authorization.

## 7. Language and motion
- All interface text in English; professional, direct and descriptive tone.
- Buttons with concrete actions; errors explain what happened and how to retry.
- Keep proper names and supplied data as given.
- Short help for complex metrics, also reachable by keyboard.
- Transitions of 150–300 ms; respect `prefers-reduced-motion`; no animations that leave panels transparent or block navigation.

## 9. Review checklist
- Shared palette only, no arbitrary accent colors.
- Inter is the main typeface; metrics use tabular figures.
- Buttons, cards and panels are treated consistently.
- The whole interface is in English.
- States never rely on color alone.
- Data sources and units are visible.
- Navigation works with the keyboard and on small screens.
- Name and content belong to the new product.
- No institutional affiliation is claimed without authorization.
